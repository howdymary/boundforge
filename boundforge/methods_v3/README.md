# New-method investigation

Started 2026-11-15 America/Los_Angeles. This is a new exploratory campaign, not a revision of earlier frozen evaluation results or the submission's historical claims.

Question: can an autonomous construction search use exact neighborhood evidence or informative interventions to make reliably better decisions than strong numerical adaptive search?

The initial audit rejects treating failure labels, contextual UCB, memory retrieval, provider integration, or conventional equioscillation as methodological novelty. Prior C49 comparisons were ceiling-limited and did not favor the full controller. Development, validation and prospective evaluation will remain separate; no new-method claim is authorized by this file.

Candidate mechanisms to investigate before implementation:
1. Exact no-improvement certificates with explicit applicability conditions, used to avoid repeating covered interventions.
2. Paired, information-seeking probes whose expected downstream value is compared with their cost.
3. Representation changes justified by measured obstruction patterns.
4. Joint allocation of construction and rigorous certification effort.

Read the source audit before choosing. Any overlap with prior art narrows or rejects the novelty hypothesis. A useful task-specific result is not automatically a general method.

Project code and experiment artifacts stay in this directory. Protected verifiers and prior reports remain unchanged. Remote execution only. No external submissions.
