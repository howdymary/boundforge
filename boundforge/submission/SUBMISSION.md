## Short description

BoundForge runs a mathematical research loop with an explicit separation between numerical promise, verified progress and achievement of the actual goal. It chooses a bounded experiment, runs a credential-free worker, diagnoses the result, retrieves scoped memory and chooses the next intervention. Exa confirms the full-precision external witness inside the loop; Tinker can propose a bounded next action. Three independent checker implementations cover the whole mathematical domain and infinite tail before a result is accepted.

For Tao's C51a, the Erdős maximum-term constant, the project certifies C51a > 0.585078819674513593, more than 1.58×10^-17 beyond an upper bound on the strongest external prior function located. This is a very small conventional parameter refinement. Decisions, exact witnesses, failures, budgets and reproduction commands are public.

The initial finding came from agent-directed research; the standalone runner demonstrates autonomous historical replay/continuation, not a blind held-out discovery. Strong fixed high precision is faster, so we do not claim a new general research method or controller advantage.

## Questions to be ready for

“Is this just a better optimizer?” The search operator is conventional equioscillation; the framework contribution is the runnable, source-gated, proof-aware loop and inspectable separation of progress from acceptance. No new algorithm claim.

“Did the standalone system discover it blindly?” No. A Codex research agent found the initial result during development. The extracted one-command controller is a transparent historical replay/continuation; saved answers are not available to proposal workers.

“Why is it a record?” The claimed lower bound beats a rigorous upper bound on the actual strongest external prior function found, not just its printed decimals. Three implementations certify the new function and its infinite tail. Public priority is scoped to the documented source audit; no external endorsement is implied.

“How large is the improvement?” More than1.58×10^-17 relative to that external function. It is extremely small and should be judged accordingly.

“Does memory or the model help?” The trace proves that a record was retrieved and influenced an action. It does not establish a general performance benefit. The fixed high-precision control is faster in this small comparison.

“Why Exa?” Its contents call recovers the exact witness missing from the search excerpt. That is a real admission gate in the main loop, with source URLs and receipts.
