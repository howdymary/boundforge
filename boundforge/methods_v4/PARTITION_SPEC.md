# Full equality strata: fixed-k arithmetic support compilation

This extends the leading novelty-mask oracle because masks forget old image identities and new-new collisions. The extension is **not** claimed new merely because it uses more features. All affine arrangement enumeration is standard; see Singular arrLattice and Macaulay2 intersectionLattice.

Fix a finite rational old support P, rational scalar linear maps l_j, and k added atoms x_1,...,x_k in Q^d. Form the affine arrangement in Q^(dk) of equations l_j(x_i)=v for every v in l_j(P), and l_j(x_i-x_h)=0 for all i<h. Enumerate every nonempty intersection flat, and choose a rational point on that flat avoiding every arrangement hyperplane that does not contain it.

**Completeness.** Every tuple x has a set of satisfied arrangement equations. Their intersection is an enumerated flat; its generic representative satisfies exactly those equations. These equations specify all equality relations among old and new images. Therefore every attainable pushforward partition tuple is represented. The representative yields exactly the same entropy vector for **every common assignment of atom probabilities**, not merely a leading asymptotic coefficient. The finiteness reduction removes a coordinate-radius parameter for fixed k/maps/old support.

The breadth-first/depth-first incremental intersection traversal is a standard exact arrangement baseline. Rational row reduction and polynomial avoidance prove realizability, but neither is new. No atom-permutation quotient is implemented. Duplicate atoms and additions coinciding with old atoms are allowed by the compiler; adapters may exclude these or combine masses. Extra domain restrictions must be encoded and certified, or no completeness claim applies.

**Cost and stopping.** The arrangement can have exponentially many flats in dk. max_flats is a hard development bound. If reached, complete=false; no full-coverage/negative result is allowed. Finite objective optimization over probability weights remains a separate problem: exhaustive geometry does not certify global optimization of nonlinear weights.

**Novelty objection.** Liu/Walsh enumerate nonisomorphic finite supports then optimize probabilities. This compiler restricts to supports realizable by specified arithmetic linear maps and a fixed incumbent, using exact equality strata. That is a potentially useful specialization and an exact reduction, but not yet evidence of a new general research method. Compare with a direct standard arrangement traversal, not just random coordinates. The current implementation literally uses such a traversal, so a better score against grid search cannot establish a new traversal algorithm.

**Model critique falsification.** A Tinker sample claimed dependent old equations are missed by masks.py because independent row subsets force dependent projections new. This is false: generic() avoids old values only on *varying* projections; dependent constant projections are classified directly. test_redundant_old_constraints_are_not_forced_new exercises the explicit counterexample. The sample's multi-atom entropy splitting extension is the standard mixing identity, not automatically a novel method. Model suggestions remain unverified hypotheses.
