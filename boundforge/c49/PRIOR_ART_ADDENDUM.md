# Memory prior art and claim boundary

Research date: 2026-11-14 America/Los_Angeles (2026-11-15 UTC). These primary abstracts were read directly after the frozen experiment; this addendum changes no evaluation policy.

[Reflexion](https://arxiv.org/abs/2303.11366) already maintains linguistic reflections in episodic memory to influence later trials. [Voyager](https://arxiv.org/abs/2305.16291) already combines a persistent executable skill library with environment feedback and iterative program improvement. [The AI Scientist](https://arxiv.org/abs/2408.06292) already implements idea generation, experiments and analysis in an iterative scientific workflow. None makes remembering failures or running a research loop a new contribution here.

BoundForge's executed controller uses small task-independent failure labels and aggregate contextual action rewards. It does not learn a new representation of scientific causes, infer causal effects from observational traces, or synthesize a generally superior research algorithm. The C49 pilot supplies paired intervention outcomes, but only from two small development families. This is a constrained application of adaptive operator selection, with an inspectable archive and exact mathematical acceptance. Methodological novelty and superiority remain unestablished.

The held-out full arm used a numerical fallback after model integration failed at the freeze. It must not be labeled a model-driven controller. Four later Tinker samples are an exploratory development component study, not a repaired or enlarged held-out comparison. Archived legacy trace strings saying "frozen model rule" describe this fallback imprecisely; the freeze artifact and report identify the actual numerical policy.

The same controller can run on cap-set and independent-set adapters, but the representations, legality checks, objectives, and several operator heuristics were human designed for each task. Code reuse and cross-task execution are engineering transfer. A general discovery advantage requires successful matched comparisons, which the initial evaluation did not establish.
