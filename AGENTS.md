# BoundForge working instructions

This repository is independent of Compute Observatory. Work on main, keep changes scoped to BoundForge, and preserve exact certificates, original attribution and archived research provenance. Do not import or modify any forecasting project. Develop through GitHub and remote execution; do not create local project files unless the user changes this preference.

Read README.md, MIGRATION.md, the comparative research review, preregistration and final research note before launching a new campaign. CONTINUE_RESEARCH.md is a reusable prompt, not an instruction to start research during unrelated maintenance.

The two exact verifiers are protected; their original SHA-256 hashes are in migration-manifest.json. Numerical scores do not accept a bound. Keep proposal generation, numerical scoring and independent exact certification separate.

All paid research workflows are manual. Migration does not authorize a new billable search. Historical provider balance snapshots are stale: refresh balances, verify existing-credit-only boundaries, reserve pending/unknown usage across projects, and establish new separate hard caps before paid work. Do not buy credits, enable auto-reload or upgrade plans. Never expose secrets or move them into source/logs. A GitHub repository secret is configured per repository.

Preserve historical logs/reports byte-for-byte where possible. Their old repository/run links are provenance, not runtime dependencies. New workflows and publishers must address this repository and main; run IDs must belong to this repository. Do not silently replay a historical record as a new discovery.
